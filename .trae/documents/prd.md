## 1. 产品概述

智慧供应链物流协同平台是一款面向企业供应链管理人员的 B 端协同工具，旨在将物流需求从发布、报价、选商到审批的全流程数字化闭环。平台通过需求池集中管理物流需求，报价对比实现透明化采购，供应商选择提供多维评估，审批状态实现流程可视化，数据 Mock 模块确保本地完整演示。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 供应链管理员 | 系统分配 | 需求发布、报价查看、供应商选择、审批发起 |
| 审批主管 | 系统分配 | 审批通过/驳回、审批记录查看 |
| 供应商 | 系统分配 | 查看需求、提交报价 |

### 2.2 功能模块

1. **需求池页面**：需求列表、需求筛选、新建需求、需求状态跟踪
2. **报价对比页面**：多供应商报价横向对比、报价详情查看、报价评分排名
3. **供应商选择页面**：供应商档案卡片、多维评分雷达图、供应商推荐排序
4. **审批状态页面**：审批流程进度条、审批记录时间线、审批操作（通过/驳回）
5. **数据 Mock 管理页面**：数据重置、数据量配置、Mock 数据预览

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 需求池 | 需求列表 | 展示所有物流需求，支持按状态、紧急程度、时间筛选 |
| 需求池 | 新建需求 | 弹窗表单，填写货物类型、起止地、数量、期望到达时间等 |
| 需求池 | 需求详情 | 抽屉面板展示需求完整信息和关联报价 |
| 报价对比 | 报价列表 | 展示某需求下所有供应商的报价摘要 |
| 报价对比 | 对比面板 | 横向并排展示各供应商报价明细，高亮最优项 |
| 报价对比 | 评分排名 | 按价格、时效、服务评分综合排名 |
| 供应商选择 | 供应商卡片 | 展示供应商资质、历史履约率、评分 |
| 供应商选择 | 雷达图评估 | 五维评估：价格、时效、服务、资质、履约 |
| 供应商选择 | 推荐排序 | 综合评分自动排序，支持手动调整权重 |
| 审批状态 | 流程进度 | 可视化展示审批节点及当前进度 |
| 审批状态 | 审批记录 | 时间线展示历史审批操作及意见 |
| 审批状态 | 审批操作 | 通过/驳回操作，填写审批意见 |
| 数据 Mock | 数据管理 | 一键重置 Mock 数据、配置各模块数据量 |
| 数据 Mock | 数据预览 | 查看当前 Mock 数据的统计摘要 |

## 3. 核心流程

用户在需求池发布物流需求后，供应商提交报价，系统在报价对比页面汇总展示，管理员根据多维评估在供应商选择页面确定供应商，随后发起审批流程，审批主管在审批状态页面完成审批。数据 Mock 模块贯穿全流程，为演示提供真实数据。

```mermaid

    "H[数据Mock模块]" -.-> "A"
    "H" -.-> "B"
    "H" -.-> "C"
    "H" -.-> "D"
    "H" -.-> "E"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深靛蓝 (#1B2A4A) + 亮橙 (#FF6B35) 强调色，传达专业与效率
- **辅助色**：浅灰背景 (#F5F6FA)、卡片白 (#FFFFFF)、状态绿 (#10B981)、警告红 (#EF4444)
- **按钮风格**：圆角 8px，主按钮填充色，次按钮描边
- **字体**：标题使用 DM Sans Bold，正文使用 DM Sans Regular
- **布局风格**：左侧导航栏 + 右侧内容区，卡片式模块布局
- **图标风格**：线性图标（Lucide Icons），2px 描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 需求池 | 需求列表 | 表格布局、状态标签着色、筛选栏、新建按钮 |
| 需求池 | 新建需求 | 模态弹窗、表单输入、下拉选择、日期选择器 |
| 需求池 | 需求详情 | 右侧抽屉面板、信息分组、关联报价卡片 |
| 报价对比 | 对比面板 | 并列卡片、高亮最优值、雷达图对比 |
| 报价对比 | 评分排名 | 条形图、排名徽章、评分星标 |
| 供应商选择 | 供应商卡片 | 网格卡片布局、资质标签、履约率进度条 |
| 供应商选择 | 雷达图评估 | Canvas 雷达图、维度标签、交互提示 |
| 审批状态 | 流程进度 | 步骤条、节点状态图标、连接线动画 |
| 审批状态 | 审批记录 | 垂直时间线、头像、操作标签 |
| 数据 Mock | 数据管理 | 操作按钮组、数据量滑块、统计卡片 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1280px
- 内容区自适应宽度，表格横向滚动
- 卡片网格响应式列数调整

### 4.4 动效设计

- 页面切换：淡入淡出 + 轻微上移
- 卡片悬停：阴影提升 + 轻微缩放
- 数据加载：骨架屏占位
- 审批流程：节点逐个点亮动画
- 表格行：悬停高亮条纹
